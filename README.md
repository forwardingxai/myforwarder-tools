# 마이포워더 도구

포워딩 실무에서 매일 반복하는 일을 AI로 하나씩 도구로 바꾸고 있어요. 로그인 없이 바로 쓰고, 만드는 방법까지 그대로 가져가세요.

## 도구

| D번호 | 도구 | 하는 일 |
|---|---|---|
| D01 | [장치장 코드 조회기](tools/bonded-area-code.html) | 이름 몇 글자, 초성, 약칭으로 전국 장치장 코드를 찾고 관세사에게 보낼 문구까지 바로 복사해요 |
| D02 | [국내 부대비용 조회기](tools/local-charge.html) | 부산항 수출 로컬차지를 39개 선사 한 번에 비교하고, 견적서 표로 복사해요 |

## 나도 만들어 보기

이 도구들은 코드를 직접 짜지 않고, AI에게 실무를 설명하면서 만들었어요. 도구마다 만든 방법을 열어 둡니다.

- `kits/{도구}.prompt.txt` — Claude 채팅에 붙여넣으면 HTML 한 파일로 같은 도구가 만들어지는 시작 프롬프트
- `kits/{도구}.md` — Claude Code·Cursor 같은 AI 코딩 도구에 넣고 쓰는 만들기 키트(데이터 얻는 법, 규칙, 단계별 프롬프트, 완성 확인)
- `data/` — 정리된 데이터(JSON, 엑셀용 CSV)

## 내 컴퓨터에서 열어 보기

파이썬이 설치돼 있다면 이 폴더에서 아래 명령을 실행하고, 브라우저에서 http://127.0.0.1:5510 을 여세요.

```
python -m http.server 5510 --bind 127.0.0.1
```

## 데이터 출처

장치장 데이터는 관세청 UNI-PASS Open API(API005 장치장 정보, API019 통계부호)에서 받아 정리했어요. 구분(CY·CFS 등)은 장치장 이름과 코드 패턴으로 추정한 값이라, 실제 신고 전에는 UNI-PASS 원본으로 한 번 더 확인해 주세요.
