## 1. 문제

### 1-1. 현재 상황
포워딩 견적 담당자가 견적을 낼 때마다, 선사마다 항목과 금액이 조금씩 다르고 정형화되어 있지 않은 로컬차지를 **각자의 로컬 파일에서 찾아 견적서 표에 옮기는 일**을 반복한다. 운영 담당자도 선사 청구서를 받을 때 같은 자료를 다시 찾아 금액을 대조한다.

### 1-2. 기존 방식의 문제
- 개인 엑셀은 갱신 시점이 제각각이다. 실제로 2026-01 기준 실무 정리본을 공식 Tariff와 대조한 결과 **92건의 차이**가 확인되었다(정부 고시 인상분 미반영, 선사 THC 인상 미반영, 서류비 일괄 기재, 입력 오류 등).
- 선사마다 항목을 묶는 방식이 달라 숫자만 비교하면 틀린다(예: 머스크는 부두사용료를 THC에 포함, 일부 선사는 부두사용료에 보안료를 합산).
- 위험물(DG)은 선사에 따라 일반 THC와 같거나 최대 약 18만 원 높아, 선사 선택에 따라 견적 차이가 크다.

### 1-3. 끝난 뒤의 모습
**부산항 수출 기준으로 컨테이너 종류·규격·수량을 고르면, 39개 선사의 로컬차지가 같은 항목 체계로 정리되어 나오고, 원하는 선사의 견적서 표를 엑셀에 그대로 붙여넣는다.** 핵심 가치는 "조회"보다 **"정형화"**다.

### 1-4. 사용자
| 사용자 | 쓰는 시점 | 주로 보는 것 |
|---|---|---|
| 영업 | 견적 작성 | 선사 비교표, 견적서 표 복사 |
| 운영 | 선사 청구서 확인·정산 | 선사별 항목 금액, 출처 링크, 포함 관계 주석 |

## 2. 입력 · 출력

### 2-1. 입력
| 입력 | 선택지 | 기본값 | 비고 |
|---|---|---|---|
| 컨테이너 종류 | DRY / DG / OT·FR / RF | DRY | DG = 드라이 컨테이너 위험물 |
| 규격 | 20' / 40' | 20' | 40'HC는 40'에 포함 |
| 수량 | 1~99 | 1 | 컨테이너당 항목에 곱함 |
| B/L 수 | 1~99 | 1 | B/L당 항목(DOCS FEE)에만 곱함 |
| 선사 범위 | 전체 / 국적 / 외국적 + 선사 검색 | 전체 | |

입력을 바꾸면 즉시 재계산한다(조회 버튼 없음). 첫 화면은 기본값으로 이미 결과가 보이는 상태로 연다.

### 2-2. 출력 A — 선사 비교표
- 열: 선사 | THC | W/FAG | PFS | PSC | SEAL | DOCS FEE | (DG일 때) DG 할증 | 합계
- 합계 = (컨테이너당 항목 합계 × 수량) + (DOCS FEE × B/L 수)
- 정렬: 합계 낮은 순(범위인 경우 최저값 기준). 공식 Tariff 미공개 선사는 표 하단 구분선 아래에 별도로 묶는다.
- 각 칸에 상태 표시(3-5 참조), 추정값이 포함된 선사의 합계에는 "추정 포함" 표시.
- **비교표 가져가기(2026-10-21 추가):** 선사 행마다 체크박스(머리 칸은 화면 전체 선택). [표 복사](탭 구분 → 엑셀에 붙여넣기)·[엑셀(CSV) 내려받기](UTF-8 BOM, 맨 위 조건 줄·맨 아래 출처 줄). 체크한 선사가 있으면 그 선사만, 없으면 화면에 보이는 선사 전체(필터·검색 반영). 열: 선사 | 국적구분 | 항목들 | 합계(최저) | 합계(최고) | 비고. 금액은 쉼표 없는 숫자, "포함"은 0, 추정·포함·오래된 공지·미확인은 비고 열에 적는다. 두 버튼은 무채색(라임은 견적서 표 복사 1개).

### 2-3. 출력 B — 견적서용 표
선사 행을 누르면 그 아래에 펼쳐진다. (예시: 하파그로이드 · DG 40' · 1개, 일부 행)

| 항목 | 단위 | 단가(KRW) | 수량 | 금액(KRW) | 비고 |
|---|---|---|---|---|---|
| THC 40' DG | 컨테이너당 | 360,000 | 1 | 360,000 | |
| W/FAG 40' | 컨테이너당 | 9,148 | 1 | 9,148 | PFS 포함(추정) |
| DG 처리 할증 | 컨테이너당 | 5,000 | 1 | 5,000 | |
| DOCS FEE | B/L당 | 40,000 | 1 | 40,000 | |

- **[견적서 표 복사]** 버튼 1개(라임). 탭 구분 텍스트로 복사하며, 금액은 쉼표 없는 숫자로 넣어 엑셀이 숫자로 인식하게 한다. 복사 후 2초간 "복사됨" 표시.
- 0원 또는 "포함"인 항목은 행으로 넣지 않고, 포함 관계는 해당 항목 비고에 적는다.
- 추정값이 포함되면 표 위에 안내 문구 고정: "이 선사는 일부 항목이 공식 확인되지 않아 같은 국적구분 선사들이 가장 많이 청구하는 금액으로 표시했습니다."
- 표 하단 고정 문구: "기준일 2026-10-20 · 선사 공식 Tariff 기준 · 부가세 별도 여부와 실제 청구액은 선사 확인 필요"
- (2026-10-21 구현 중 결정, 확인 필요) 범위 추정 항목은 단가·금액을 "최저~최고" 글자로 넣는다(복사해도 숫자로 지어내지 않음 — 엑셀 SUM에서 빠지므로 선사 확인 후 숫자로 고친다). 추정 항목 비고에는 근거를 짧게 적는다(예: "추정(확인된 외국적 선사 7곳 중 6곳)") — 휴대폰은 툴팁이 안 보여서.

### 2-4. 표시하지 않는 것 (1단계)
부가세 계산, 외화 항목, 해상 할증료(BAF·LSS 등), 45' 규격, 리퍼·특수 컨테이너 위험물, 항로별 선택.

### 3-4. 대표값 선택 규칙
한 선사에 같은 항목이 여러 행이면 아래 순서로 1개를 고른다. 값이 여러 개면 범위(최저~최고)를 함께 저장해 툴팁으로 보여준다.
1. 부산 정확일치(KRPUS) > 전국 공통(ALL)
2. 전 항로 · 한중 · 한일 · 아시아 항로 > 특정 원양 항로
3. (DG) IMO 3~9급 > IMO 1·2·7급
4. 최신 발효일

**DG 판정 규칙:** DG 행 중 리퍼·오픈탑·플랫랙·탱크 기반 위험물은 제외하고 **드라이 컨테이너 위험물만** DG로 취급한다. 화면에 기준을 고정 표기: "DG 기준: 드라이 컨테이너 위험물, 한중·아시아 항로, IMO 3~9급".

### 3-5. 상태 체계

| 일반 서류비 적용 | 위험물 서류비 고시 없음 | 일반 DOCS FEE 사용 | — |

### 3-6. 추정 규칙 (선사 값이 없을 때)
1. 같은 **국적구분 그룹(국적 / 외국적)** 의 확인 선사 값을 근거로 한다. 그룹 내 확인 선사가 5곳 미만이면 전체 선사로 넓힌다.
2. 최빈값이 근거 선사의 **50% 이상**이면 최빈값을 쓴다. 안내 문구: "이 선사의 ○○는 확인되지 않았습니다. 확인된 외국적 선사 14곳 중 9곳이 210,000원을 청구합니다."
3. 50% 미만이면 최빈값 대신 **범위**로 안내한다. 예: 외국적 DG 40' THC는 190,000~385,000원(12곳).
4. 근거 선사가 5곳 미만이면 추정하지 않는다.
5. 선사 고유 항목(위험물 서류비, DG 할증)은 추정하지 않는다.
6. 추정값은 반드시 "추정"으로 표기한다(데이터 원칙).

> 국적·외국적을 나누는 이유: DG 40' THC의 경우 국적선사는 대부분 일반 THC와 같은 210,000원, 외국적선사는 270,000~385,000원이다. 전체 최빈값을 쓰면 외국적 미공개 선사(MSC 등)가 과소 산정된다.

### 3-7. 이중 계산 방지
- 부산 W/FAG가 4,574원/9,148원인 선사(= 4,429원/8,858원 + 보안료 145원/290원)는 PFS를 "W/FAG에 포함"으로 처리하고 추정값을 채우지 않는다.
- 머스크는 W/FAG가 THC에 포함되어 있어 W/FAG를 추정하지 않는다.

### 3-9. 갱신
- 주기: 월 1회.
- 방법: aside로 같은 조건 재수집 → `raw/aside-YYYY-MM-DD/`에 저장 → `python scripts/build_busan_export.py raw/aside-YYYY-MM-DD data/local-charge-busan-export.json` → `python scripts/local_charge_csv.py`(키트용 CSV, 표준 라이브러리만) → 이전 데이터와 차이 확인 → 커밋·push(자동 배포).
- 화면의 기준일은 JSON `meta.checked_at`에서 읽는다.
- 선사 PDF·XLSX 파일명은 개정 때마다 바뀌므로 고정 URL을 저장하지 않는다(aside `automation_hint` 참조).
