# API005 장치장 정보 — D01 작업 메모

> 2026-10-16 정리 · 근거: UNI-PASS OpenAPI 연계가이드 v4.1 3.2.5절(원본 PDF는 `docs/reference/`, 커밋 제외)
> 아직 실제 호출 전. "확인 필요"는 시험 호출로 확정한다.

## 1. 요약

| 질문 | 답 | 근거 수준 |
|---|---|---|
| 목록형인가, 건별형인가 | **목록형.** 한 번 호출에 여러 장치장이 돌아오고, 조건 2개(관할세관·장치장부호)는 모두 선택 | 가이드 명시 |
| 조건 없이 부르면 전국 전체가 오는가 | 가이드에 없음 | **확인 필요** |
| 전국 수집 호출 수 | 조건 없이 전체가 오면 **1회.** 안 되면 **관할세관 수만큼**(세관마다 1회) | 추정 |
| 페이지 나눔 | 요청 항목에 페이지 번호·건수 항목이 없음 → 한 번에 다 주는 방식으로 보임 | 추정 |
| 일일 호출 한도 | 가이드에 없음. 1~수십 회 수준이라 걸릴 가능성은 낮음 | **확인 필요** (UNI-PASS OpenAPI 사용관리 화면 또는 시험 호출) |
| 응답 형식 | **XML만** (JSON 없음), UTF-8 | 가이드 명시 |

## 2. 요청

- 주소: `https://unipass.customs.go.kr:38010/ext/rest/shedInfoQry/retrieveShedInfo`
- 방식: REST GET, HTTPS(TLS 1.2 이상), IP가 아닌 도메인으로 호출
- 파라미터

| 이름 | 뜻 | 길이 | 필수 |
|---|---|---|---|
| `crkyCn` | 인증키 (`.env`의 `UNIPASS_API005_KEY`) | — | 필수 |
| `jrsdCstmCd` | 관할세관코드 | 3 | 선택 |
| `snarSgn` | 보세구역부호(장치장부호) | 8 | 선택 |

- 인증키가 주소 안에 들어가므로 **요청 주소 전체를 로그·파일·화면에 남기지 않는다.** 스크립트는 키를 가린 주소만 출력한다.

## 3. 응답

- 뿌리 태그 `shedInfoQryRtnVo` 안에 장치장 1건마다 `shedInfoQryRsltVo`가 반복된다.
- 오류: `tCnt`가 `-1`이고 `ntceInfo`에 한글 사유가 들어온다(예: 존재하지 않는 인증키). 결과가 없을 때 "조회된 정보가 없습니다" 같은 문구가 올 수 있다.
- 가이드 예제에 `tCnt`(건수)가 빠져 있다. 건수는 반복 태그 수로 센다.
- 가이드 표기가 엇갈리는 곳이 있다. 하역장소 여부 태그가 표에서는 `ldunPlcSnarYn`, 예제에서는 `LdunPlcSnarYn`로 적혀 있다. 그래서 **태그 이름의 대소문자는 구분하지 않고 읽는다.**

| 응답 항목 | 뜻 | 길이 | 비고 |
|---|---|---|---|
| `snarSgn` | 보세구역부호 | 8 | 항상 옴 |
| `snarNm` | 보세구역명 | 150 | 항상 옴 |
| `snarAddr` | 보세구역 주소 | 500 | 없을 수 있음 |
| `snartelno` | 전화번호 | — | **수집하지 않음**(PRD 3-1 공개 원칙) |
| `pnltLvyTrgtYn` | 과태료 부과대상 여부 Y/N | 1 | 도구에서 안 씀 |
| `adtxColtPridYn` | 가산세 징수 여부 Y/N | 1 | 도구에서 안 씀 |
| `ldunPlcSnarYn` | 하역장소 보세구역 여부 Y/N | 1 | 구분(type) 판단 보조로 검토 |

## 4. PRD 3-2 필드 대응

| PRD 필드 | API005 응답 | 처리 방법 | 남은 결정 |
|---|---|---|---|
| `code` | `snarSgn` | 문자열로 저장해 앞자리 0 보존 | — |
| `name` | `snarNm` | 원문 그대로. 검색용 정규화는 화면에서 | — |
| `customs` | **없음** | 세관부호는 요청에 넣은 `jrsdCstmCd`를 쓴다. 가이드 예제에서는 부호 앞 3자리가 세관코드와 같았다(추정, 시험 호출로 확인). **세관명**은 별도 목록이 필요 | 세관명 목록을 어디서 받을지 |
| `region` | **없음** | PRD대로 세관부호·주소(`snarAddr`)에서 부산/인천/광양/평택/울산/공항/기타로 파생 | 세관→지역 매핑표 작성 |
| `type` | **없음** | CY/CFS/보세창고/공항화물 구분 항목이 응답에 없다. 이름 키워드와 `ldunPlcSnarYn`으로 나누면 **추정값**이 된다 | 추정 태그를 붙일지, 구분 필터를 뺄지 |
| `address` | `snarAddr` | 있으면 저장 | — |
| `aliases` | **없음** | PRD대로 1차는 수동 보강 10~20건 | — |
| (만료 상태) | **없음** | 폐지·특허만료 상태 항목이 없어 PRD 3-3의 "만료" 태그를 붙일 수 없다. 응답에 현행만 오는지 | **확인 필요** |

## 5. 세관명 목록을 얻는 길 (참고)

- 같은 가이드의 **API019 통계부호**에서 구분 `A09`(세관부호)를 주면 세관 목록이 온다. 구분 `A08`(보세구역 부호)도 있지만 코드명이나 코드값을 넣어야 해서 전체 목록용은 아니다.
- **API031 우편번호별 관할세관**은 우편번호 1개당 세관을 알려 준다. 전체 목록용은 아니다.
- 둘 다 API005와 별도 서비스라 사용 신청과 승인이 따로 필요하다.

## 6. 시험 호출로 확인할 것 (승인 후 1~2회)

1. 조건 없이 호출 → 전국 전체가 오는지, 몇 건인지
2. 조건 없이 안 되면 `jrsdCstmCd` 1개로 호출 → 그 세관 분만 오는지, 부호 앞 3자리와 세관코드가 같은지
3. `snarNm`·`snarAddr`가 실제로 채워져 오는지(가이드 예제는 비어 있음)
4. 일일 호출 한도는 UNI-PASS OpenAPI 사용관리 화면에서 확인
