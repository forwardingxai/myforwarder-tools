## 1. 문제

- 관세사가 수출입 신고를 위해 "장치장 코드가 어떻게 되나요?"라고 묻는다.
- 담당자는 개인 메모를 뒤지거나 선사·창고에 다시 확인해 장치장명과 8자리 부호를 보낸다.
- 목표: 장치장명 일부만 입력하면 공식 부호가 나오고, 관세사에게 보낼 문구가 한 번에 복사된다.

## 2. 데이터 — 관세청 UNI-PASS Open API

### 2-1. 신청 (무료, 승인 즉시)
1. UNI-PASS(unipass.customs.go.kr) 회원 가입 후 로그인
2. My 메뉴 → 서비스관리 → OpenAPI 사용관리
3. 두 서비스를 신청한다. 서비스마다 인증키가 따로 나온다.
   - **API005 장치장 정보**: 보세구역(장치장) 부호·이름·주소
   - **API019 통계부호**: 세관부호 목록(관할세관 코드와 세관명)
4. 인증키는 작업 폴더의 `.env`에만 저장하고, `.gitignore`에 `.env`를 넣어 절대 커밋하지 않는다.
   ```
   UNIPASS_API005_KEY=발급받은키
   UNIPASS_API019_KEY=발급받은키
   ```

### 2-2. 호출 방식 (2026-10 실제 호출로 확인한 내용)
- 응답은 XML만 온다(JSON 없음). 오류면 건수(`tCnt`)가 `-1`이고 `ntceInfo`에 한글 사유가 온다.
- **API019**: `statsSgnTp=A09` 한 번이면 세관부호 60건이 온다. 실제 응답 항목 이름은 개발가이드 표와 다르게 `cdValtVal`(부호)·`cdValtValNm`(이름)이었다. `000`~`009`는 관세청 본청·부서라서 장치장 조회 대상에서 뺀다 → 세관 50곳.
- **API005**: 조건 없이 부르면 "관할세관코드 또는 보세구역부호는 필수"라는 오류가 난다. 관할세관코드(`jrsdCstmCd`)를 넣어 **세관마다 1회씩** 부른다 → 전국 50회. 세관 1곳 분량은 한 번에 다 온다(페이지 나눔 없음).
- 일일 호출 한도는 문서에서 확인하지 못했다. 호출 사이에 1초를 쉬고, 오류 응답이 오면 즉시 멈추게 만든다.
- 원본 응답은 `raw/` 폴더에 세관별로 저장해서 중간에 멈춰도 이어받게 하고, `raw/`도 커밋하지 않는다.
- 2026-10-17 기준 전국 3,426건, 세관 사이 중복 부호는 없었다.

## 3. 정제 필드

| 필드 | 내용 |
|---|---|
| `code` | 장치장 부호 8자리. **문자열로 저장해 앞자리 0 보존** |
| `name` | 장치장명(공식) |
| `customs` / `customsName` | 요청에 넣은 관할세관 부호 / API019에서 찾은 세관명. 부호 앞 3자리와 관할세관이 다를 수 있으니 부호에서 잘라 쓰지 않는다 |
| `region` | 관할세관 기준 지역(부산·인천·광양·평택·울산·서울·경기·경남·공항·기타). 지원센터는 센터 소재지 기준 |
| `type` | 구분(**추정**) — 4절 규칙 |
| `address` | 주소 |
| `aliases` | 실무 약칭(예: HPNT, PNIT). 손으로 보강 |

- 원본의 전화번호는 수집하지 않는다.
- 데이터 파일 머리에 출처·기준일·건수·범위를 적는다.

## 4. 구분(type) 추정 규칙

API005에는 CY·CFS 같은 구분 항목이 없다. 그래서 아래 순서로 추정하고, 화면에 항상 "추정" 표시를 붙인다.

0. 인천공항세관(040) 관할이고 이름에 `항공`·`터미널`이 있으면 공항화물(이름으로 다른 구분이 분명하면 그쪽)
1. 이름 키워드(위에서부터 먼저 걸리는 것): 지정장치장 → 세관검사장 → `보세구역외` → CFS → 보세판매장(`면세점`·`인도장`) → 공항화물(`공항`·`항공화물`·낱말 앞의 `항공`) → 탱크터미널은 보세창고 → CY(`컨테이너터미널`·`CY`·`터미널`) → 자유무역지역 → 보세공장(`공장`) → 보세창고(`창고`·`물류`·`냉장`·`로지스` 등)
2. 이름으로 안 되면: 부호 4~5번째 자리가 `12`·`77`·`78`이고 하역장소 여부가 Y면 CY
3. 그래도 안 되면 부호 4~5번째 자리 패턴: `01` 세관검사장, `02` 지정장치장, `06`·`07`·`10`·`11`·`13`·`70` 보세창고, `12` CY, `86` CFS, `16`·`18`·`20` 보세공장, `19` 보세구역외장치, `21`·`22`·`24`·`25` 보세판매장, `77`·`78` 자유무역지역 (공식 문서가 아니라 데이터에서 관찰한 패턴)
4. 나머지는 기타 — 2026-10-17 기준 8.2%

## 5. 검색·복사 규칙

- 공백·괄호·㈜·(주)·주식회사 무시, 대소문자 무시, 초성 검색, 약칭 검색, 코드 부분 일치
- 정렬: 정확 일치 → 앞부분 일치 → 중간 일치 → 이름순
- 복사 형식 3가지: `장치장: {name} / 장치장코드: {code}` · `{name}<탭>{code}`(여러 줄) · `{code}`
- 즐겨찾기·최근 조회 10건·내 메모는 브라우저 localStorage에만 저장(서버·로그인 없음)

## 6. 단계별 프롬프트

AI에게 한 번에 다 시키기보다 아래처럼 나눠서 시키고, 단계마다 결과를 확인하세요.

**01 역할 지정**
```
너는 포워딩 실무자를 돕는 웹 도구 개발자야. 이 폴더의 kit 파일(장치장 코드 조회기)을 읽고, 무엇을 만들지 5줄로 요약한 뒤 작업 계획을 단계별로 보여 줘. 단계마다 멈추고 나에게 확인받아. 나는 코딩 초보자라 명령어는 한 줄씩 설명해 줘.
```

**02 데이터 수집·정제**
```
kit 2·3절대로 scripts/fetch.mjs를 만들어 줘. .env의 키를 쓰되 키와 키가 들어간 주소는 절대 출력·저장하지 마. 먼저 API019 A09로 세관 목록을 받고, API005는 세관 1곳만 시험 호출해서 응답 구조를 보여 준 뒤 내 승인을 받고 전국을 받아. 결과는 data/bonded-areas.json.
```

**03 검색·정렬 규칙**
```
kit 5절의 검색·정렬 규칙을 함수로 만들고, "HPNT", "ㅂㅅㅅㅎ", "0307701", "(주) 부산신항 국제터미널" 네 가지로 결과를 표로 보여 줘.
```

**04 초성·별칭 처리**
```
초성 검색과 약칭(aliases) 검색을 추가해 줘. 약칭으로 찾았으면 "약칭 ○○ 일치"를 보여 주고, 내가 자주 쓰는 약칭을 손으로 추가할 수 있는 파일을 따로 둬.
```

**05 복사 형식 설계**
```
kit 5절의 복사 형식 3가지를 만들고, 체크한 여러 건을 한 번에 복사하는 "관세사 전달용 복사" 버튼을 하나만 눈에 띄게 둬. 고른 형식은 기억해.
```

**06 출력 형식**
```
tools/bonded-area-code.html 한 파일로 화면을 완성해 줘. 넓은 화면은 입력 왼쪽·결과 오른쪽, 768px 이하는 검색창 → 결과 순서, 필터는 접기. 구분에는 "추정" 표시. 다 되면 7절 확인 목록을 브라우저에서 직접 해 보고 결과를 표로 알려 줘.
```

## 9. 주의

- 인증키는 `.env`에만. 채팅·코드·커밋에 넣지 않는다.
- 관세청 공공데이터이므로 화면에 출처와 기준일을 표시한다. 데이터는 바뀔 수 있으니 분기마다 다시 받는다.
