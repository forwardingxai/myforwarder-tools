너는 포워딩·통관 실무자를 돕는 웹 도구 개발자야. 아래 조건대로 "장치장 코드 조회기"를 HTML 파일 하나로 만들어 줘. 외부 라이브러리 없이 HTML·CSS·JavaScript만 써.

[목적]
관세사가 "장치장 코드가 어떻게 되나요?"라고 물을 때, 장치장명 일부·코드·초성·약칭으로 찾아서 관세사에게 보낼 문구를 바로 복사한다.

[데이터]
- 화면 위쪽에 "데이터 불러오기" 버튼을 두고, 내가 JSON 파일을 고르면 읽어 와. 불러오기 전에는 사용법 안내만 보여 줘.
- 데이터 파일 받는 곳: {{DATA_URL}} (관세청 UNI-PASS 공개 데이터를 정리한 파일. 화면 아래에 출처를 적어 줘)
- 파일 모양: {"updatedAt": "YYYY-MM-DD", "count": 3426, "items": [{"code": "03077011", "name": "에이치엠엠피에스에이신항만(주)", "customs": "030", "customsName": "부산세관", "region": "부산", "type": "CY", "address": "부산광역시 강서구 ...", "aliases": ["HPNT", "현대신항"]}]}
- code(장치장 부호)는 항상 문자열로 다뤄서 앞자리 0을 지켜.
- type(구분)은 이름으로 추정한 값이라 화면에 작은 "추정" 표시를 붙여.

[검색 규칙]
- 공백·괄호·㈜·(주)·주식회사는 무시하고, 영문 대소문자도 무시해.
- 초성만 입력하면(예: ㅂㅅㅅㅎ) 장치장명의 초성과 비교해.
- aliases(약칭)도 검색하고, 약칭으로 찾았으면 "약칭 HPNT 일치"처럼 보여 줘.
- 코드는 부분 일치로 찾아.
- 정렬: 정확히 일치 → 앞부분 일치 → 중간 일치 → 이름순.
- 일치한 글자는 하이라이트해.

[화면]
- 넓은 화면은 왼쪽에 검색창·필터, 오른쪽에 결과. 좁은 화면(768px 이하)은 검색창 → 결과 순서.
- 필터: 지역(region), 구분(type), 세관(customsName). 여러 개 고를 수 있게.
- 결과 한 줄: 체크박스 · 장치장명 · 코드 · 세관 · 구분(추정) · 즐겨찾기 별 · 복사 버튼.
- 결과가 많으면 50건씩 "더 보기".
- 빈 상태 문구: "장치장명이나 코드를 입력하세요. 초성 검색도 됩니다."
- 결과 없음 문구: "일치하는 장치장이 없습니다. 이름 일부만 입력해 보세요."

[복사]
- 형식 3가지를 고를 수 있게 하고, 고른 형식을 기억해.
  1) 한 줄: 장치장: {name} / 장치장코드: {code}
  2) 표: {name}(탭){code} — 여러 건이면 줄바꿈으로 이어서, 엑셀·메일 표에 바로 붙게
  3) 코드만: {code}
- 체크한 항목을 한 번에 복사하는 "관세사 전달용 복사" 버튼을 하나 두고, 이 버튼만 눈에 띄는 색으로 해.
- 복사하면 "복사됨 — 관세사에게 붙여넣으세요" 알림을 잠깐 보여 줘.

[저장]
- 즐겨찾기, 최근 조회 10건, 장치장별 내 메모를 브라우저 localStorage에 저장해. 로그인·서버는 쓰지 마.

[디자인]
- 흰 바탕, 검정 글자, 버튼과 태그는 둥근 알약 모양. 색은 실행 버튼 하나와 선택된 필터에만.

[완성 확인] 다 만들면 아래 4가지를 직접 해 보는 방법을 알려 줘.
1. "HPNT"를 검색하면 03077011이 맨 위에 나온다.
2. "ㅂㅅㅅㅎ"(초성)로 검색하면 부산신항 관련 장치장이 나온다.
3. 결과 2건을 체크하고 "표" 형식으로 복사하면 탭으로 나뉜 2줄이 복사된다.
4. 즐겨찾기와 메모를 저장하고 새로고침해도 남아 있다.
