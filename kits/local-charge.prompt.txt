너는 포워딩 영업·운영 실무자를 돕는 웹 도구 개발자야. 아래 조건대로 "국내 부대비용 조회기"를 HTML 파일 하나로 만들어 줘. 외부 라이브러리 없이 HTML·CSS·JavaScript만 써.

[목적]
부산항 수출 컨테이너(FCL) 견적을 낼 때, 컨테이너 종류·규격·수량만 고르면 선사 39곳의 로컬차지(THC·W/FAG·PFS·PSC·SEAL·DOCS FEE)를 같은 항목으로 맞춰 비교하고, 고른 선사의 견적서 표를 엑셀에 그대로 붙여넣는다. 운영 담당자는 선사 청구서 금액을 대조할 때 쓴다.

[데이터]
- 화면 위쪽에 "데이터 불러오기" 버튼을 두고, 내가 JSON 파일을 고르면 읽어 와. 불러오기 전에는 사용법 안내만 보여 주고, 불러오면 바로 기본값(DRY · 20' · 1개 · B/L 1 · 전체)으로 결과가 보이게 해.
- 데이터 파일 받는 곳: {{DATA_URL}} (각 선사 공식 사이트의 공개 Tariff를 정리한 파일. 화면 아래에 출처와 기준일을 적어 줘)
- 파일 모양:
  {"meta": {"checked_at": "2026-10-20", "source": "..."},
   "items": [{"key": "THC_DRY_20", "label": "THC 20' DRY", "unit": "PER_CNTR"}, ...],
   "carriers": [{"carrier_id": "kmtc", "name_ko": "고려해운", "name_en": "...", "nationality": "국적", "page_url": "https://...",
     "values": {
       "THC_DRY_20": {"status": "확인", "amount": 150000, "range": null, "effective_from": "2026-01-01"},
       "SECURITY_20": {"status": "미확인", "estimate": {"type": "mode", "amount": 145, "basis_group": "외국적", "n_same": 7, "n_total": 8}},
       "SEAL": {"status": "미확인", "estimate": {"type": "range", "range": [8000, 15000], "basis_group": "외국적", "n_total": 12}}, ...}}]}
- 항목 키: THC_{DRY|DG|OOG|RF}_{20|40}, WHARFAGE_{20|40}(W/FAG), SECURITY_{20|40}(PFS 항만시설보안료), PORT_SAFETY_{20|40}(PSC 항만안전관리비), SEAL, DOC_FEE(B/L당), DOC_FEE_DG(위험물 서류비, B/L당), DG_SURCHARGE(DG 처리 할증)

[상태 → 합계·표시]
- 확인: 금액 그대로. range가 있으면 마우스를 올렸을 때 "항로·조건에 따라 최저~최고원"
- 확인(오래된 공지): 금액 + 작은 연도 태그(effective_from의 연도)
- THC에 포함 / W/FAG에 포함(추정): 0원, 칸에 "THC 포함" / "W/FAG 포함"
- 일반 서류비 적용 / 해당 없음: 0원, 칸에 "—"
- 미확인 + estimate.type "mode": 그 금액을 회색 글자 + "추정" 태그. 마우스를 올리면 "확인된 {basis_group} 선사 {n_total}곳 중 {n_same}곳이 {amount}원을 청구합니다."
- 미확인 + estimate.type "range": "최저~최고"를 회색 글자 + "추정". 합계도 최저~최고로 계산. 마우스를 올리면 "확인된 {basis_group} 선사 {n_total}곳 기준 {최저}~{최고}원"
- 미확인 + estimate 없음: 0원, "미확인"
- 추정값은 반드시 "추정"이라고 표시해. 지어낸 숫자를 확인값처럼 보여 주면 안 돼.
- basis_group이 "전체"면 문구에서 그룹 이름을 빼고 "확인된 선사 17곳 중 17곳"처럼 써.

[계산]
- 입력: 컨테이너 종류(DRY/DG/OT·FR/RF, OT·FR은 키에서 OOG), 규격(20'/40'), 수량(1~99), B/L 수(1~99), 선사 범위(전체/국적/외국적), 선사 검색
- 비교표 열: 선사 | THC | W/FAG | PFS | PSC | SEAL | DOCS FEE | (DG일 때) DG 할증 | 합계
- 합계 = (컨테이너당 항목 합 × 수량) + (DOCS FEE × B/L 수)
- DG일 때: DOC_FEE_DG가 "확인"이면 DOC_FEE 대신 쓰고, DG_SURCHARGE가 "확인"이면 컨테이너당으로 더해. DG 고르면 입력 아래에 "DG 기준: 드라이 컨테이너 위험물, 한중·아시아 항로, IMO 3~9급"을 보여 줘.
- 정렬: 합계 낮은 순(범위면 최저값 기준). values 전체(18개 항목)에 "확인"으로 시작하는 상태가 하나도 없는 선사는 표 아래 구분선 "공식 Tariff 미공개 선사 (추정값)" 밑에 따로 묶어(고른 조건과 상관없이 늘 같은 9곳).
- 입력을 바꾸면 조회 버튼 없이 바로 다시 계산해. 첫 화면은 DRY · 20' · 1개 · B/L 1 · 전체로 이미 결과가 보이게.

[견적서용 표]
- 선사 이름 옆에 작은 세모(▸)를 두고, 그 행을 누르면 바로 아래에 견적서용 표가 펼쳐지게(세모는 ▾로).
- 열: 항목 | 단위 | 단가(KRW) | 수량 | 금액(KRW) | 비고. 항목은 items의 label, 단위는 "컨테이너당" 또는 "B/L당", 수량은 컨테이너당 항목이면 컨테이너 수·B/L당 항목이면 B/L 수.
- 합계 줄은 넣지 마(붙여넣은 뒤 엑셀 SUM으로 더할 때 두 번 더해지지 않게).
- 추정 항목 비고에는 근거를 짧게 적어(예: "추정(확인된 외국적 선사 7곳 중 6곳)", "추정 범위(확인된 외국적 선사 12곳)"). 범위 추정 항목은 단가·금액을 "최저~최고" 글자로 넣어(숫자를 하나 골라 지어내지 않게).
- 0원이거나 "포함"인 항목은 행으로 넣지 말고, 포함 관계는 관련 항목 비고에 적어(W/FAG 비고 "PFS 포함(추정)", THC 비고 "W/FAG 포함").
- 추정값이 있으면 표 위에 "이 선사는 일부 항목이 공식 확인되지 않아 같은 국적구분 선사들이 가장 많이 청구하는 금액으로 표시했습니다."
- 표 아래에 "기준일 {checked_at} · 선사 공식 Tariff 기준 · 부가세 별도 여부와 실제 청구액은 선사 확인 필요"
- [견적서 표 복사] 버튼 하나만 눈에 띄는 색으로. 탭으로 나눈 텍스트로 복사하고 금액은 쉼표 없는 숫자(엑셀이 숫자로 알아보게). 복사 후 2초간 "복사됨".

[화면]
- 흰 바탕, 검정 글자, 버튼과 태그는 둥근 알약 모양. 고른 입력 칸은 검정 채움 + 흰 글자로 또렷하게.
- 선사명은 page_url이 있으면 새 창 링크.
- 좁은 화면(768px 이하)에서는 표를 가로로 밀 수 있게 하고, 선사명 열과 합계 열은 고정해.
- 상태 표시는 색이 아니라 회색 글자 태그로(색으로만 의미를 전하지 않게).
